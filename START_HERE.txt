台灣飛行模擬器 v9｜瀏覽器一鍵啟動版

【啟動遊戲】
1. 將 ZIP 完整解壓縮到電腦資料夾（不要直接在壓縮檔內執行）。
2. 打開 Taiwan_FlightSim_RealMap_Package 資料夾。
3. 雙擊「台灣飛行模擬器.vbs」。
4. 程式會在背景啟動本機伺服器，並自動開啟預設瀏覽器進入模擬器。
5. 不需要點 BAT、不需要手動開 PowerShell，也不需要輸入網址或指令。

【關閉背景伺服器】
雙擊「關閉模擬器.vbs」。

【必要條件】
- Windows 10/11，且 Windows Script Host 與 PowerShell 可正常使用。
- 已安裝 Python 3；安裝時建議勾選「Add Python to PATH」，也可使用 Python Launcher（py）。
- 地圖底圖與部分機場影像需要網路連線。

【注意】
- 請保留整個資料夾結構，尤其是 data 資料夾；不要只移動 index.html。
- 不建議直接雙擊 index.html，因為瀏覽器可能限制讀取本機地形資料。
- 若 8000 埠被占用，啟動器會自動改試 8001 至 8010。
- 背景伺服器只綁定本機 127.0.0.1。
- 本版本使用 VBS 作為免命令視窗啟動入口，並非獨立 EXE；不需要安裝額外的遊戲執行環境，但仍需要 Python 3。
